{{- /* 统一图片输出 —— 全站的 都应该从这里出 --------------------------------------------------------------------------- 好处有二： 1. 图片放在 assets/uploads/ 里时，Hugo 会先缩放、转成 WebP 再发出去。 商会同事用手机直拍的照片动辄 5–10MB，原样砸给访客既慢又费流量。 2. 输出的 带 width/height。浏览器能提前按比例占好位置，图片加载完成 时页面不会「跳一下」（CLS）。静态目录里的图片拿不到这两个值。 参数（dict） --------------------------------------------------------------------------- src 必填，图片路径，如 /uploads/news/xxx.jpg。前导斜杠可有可无； 也可以直接给 http(s) 外链（外链不会被处理，原样输出）。 alt 选填，但正文图强烈建议给 —— 它同时是图注和读屏软件念的内容。 title 选填，鼠标悬停提示。 width 选填，缩放后的最大宽度（像素），默认 1200。传 0 表示只转格式不缩放。 ⚠ 这是「最大」宽度：比它小的图不会被放大，只转格式。 class 选填，附加在 上的 class。 loading 选填，默认 "lazy"。首屏就会看到的图（轮播、文章头图）传 "eager"， 否则浏览器可能因为图还没加载完而让首屏空一块。 fetchpriority 选填，默认 ""（不输出该属性）。真正是 LCP 的那张图传 "high"： 首屏轮播的第一张、文章头图、以及没有头图时正文的第一张图。 只对首屏那一张有意义，其余都别传。 为什么能安全地混用两种目录 --------------------------------------------------------------------------- resources.Get 只认 assets/ 里的文件。拿不到就退回普通 ，也就是： 老图继续留在 static/uploads/ 也照样显示，只是没有压缩和宽高。 所以图片可以逐张、逐栏目从 static/ 搬到 assets/，不会因为漏搬而破图。 CDN 扩展点 --------------------------------------------------------------------------- 站内路径统一过一道 components/cdn-url.html。site.Params.cdnBase 为空（默认） 时它原样返回，输出与本功能不存在时逐字节一致；填上域名即整站图片改走 CDN。 详见 docs/IMAGES-AND-OSS.md。 */ -}} {{- $src := .src | default "" -}} {{- $alt := .alt | default "" -}} {{- $title := .title | default "" -}} {{- $loading := .loading | default "lazy" -}} {{- $class := .class | default "" -}} {{- $fetchpriority := .fetchpriority | default "" -}} {{- /* ⚠ 不能用 `default 1200`：Hugo 的 default 把 0 当作「空」，传 width=0 （文档里承诺的「只转格式、不缩放」）会被顶成 1200，于是永远走缩放分支， 大图仍被压到 1200 —— 参数静默失效。必须用 isset 区分「没传」和「传了 0」。 同仓库的 components/news-list.html 已用 isset 躲开这个坑，这里当初漏了。 */}} {{- $max := 1200 -}} {{- if isset . "width" }}{{ $max = .width }}{{ end -}} {{- /* 外链不做任何处理，也不去 assets 里找，更不套 CDN 前缀 */ -}} {{- $external := or (hasPrefix $src "http://") (hasPrefix $src "https://") (hasPrefix $src "//") -}} {{- $res := "" -}} {{- if not $external -}} {{- $res = resources.Get (strings.TrimPrefix "/" $src) -}} {{- end -}} {{- /* 只有位图能被缩放/转码。刻意不含 gif：动图转 WebP 会丢掉动画。 也不含 svg：它是矢量图，没有像素宽度，缩放无意义。 ⚠ 但「不转码」不等于「读不出尺寸」：gif Hugo 仍能解码，尺寸要补上， 见下面的 $rawW/$rawH —— fallback 分支以前完全不输出宽高，是会招 CLS 的。 svg 与「assets 里找不到该文件」这两种情况，建站期确实拿不到尺寸， 只能输出没有宽高的 ，这是已知且无法在本地解决的残缺点。 */ -}} {{- $processable := false -}} {{- $rawW := 0 -}} {{- $rawH := 0 -}} {{- with $res -}} {{- $sub := .MediaType.SubType -}} {{- if in (slice "jpeg" "png" "webp" "bmp" "tiff") $sub -}} {{- $processable = true -}} {{- else if eq $sub "gif" -}} {{- $rawW = .Width -}} {{- $rawH = .Height -}} {{- end -}} {{- end -}} {{- if $processable -}} {{- $img := $res -}} {{- if and (gt $max 0) (gt $res.Width $max) -}} {{- $img = $res.Resize (printf "%dx webp q82" $max) -}} {{- else -}} {{- $img = $res.Process "webp q82" -}} {{- end -}} {{- else -}} {{- $u := $src -}} {{- if not $external -}} {{- $u = partial "components/site-url.html" $src -}} {{- $u = partial "components/cdn-url.html" $u -}} {{- end -}} {{- end -}}

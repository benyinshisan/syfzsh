## 2. 为什么排除了 EdgeOne 个人版

| 项 | 事实 |
| --- | --- |
| 价格 | **¥29.9/月**（另有免费版，限量内测、无 SLA） |
| 含流量 | 50 GB/月 + 300 万请求，超出 **0.31 元/GB**（大陆档） |
| **大陆节点** | **无备案不可用。** 官方原文：「未 ICP 备案域名，加速区域不可选全球可用区或中国大陆可用区，**仅可选择全球可用区（不含中国大陆）**」 |
| 免费版额外限制 | **不面向「高比例图片 / 音视频 / 大文件」业务** —— 本站是图片站，属于灰区 |
| 非大陆区域实测 | 社区报告：平台自带域名在大陆访问直接 **401**，且存在被分配到不可达节点的情况（非官方） |

结论：**它的价值全在「有大陆节点」，而没有备案就拿不到**。那就没有任何理由选它 —— 同样是海外节点，Cloudflare 是免费的。

## 3. 为什么「备案 + 大陆节点」被暂时排除 —— 以及它的真实成本

### 3.1 三条硬事实

**（1）大陆 CDN 一律需要备案。** 阿里云、腾讯云、EdgeOne、又拍云、七牛云，没有例外。

**（2）备案需要一个「备案资源」，而 CDN / 对象存储 / EdgeOne 都不算。**
腾讯云《备案云资源》的正面清单**只有 6 项**：CVM、轻量应用服务器 Lighthouse、Serverless 云函数资源包、负载均衡实例、备案授权码、云开发。
→ **COS 不在、CDN 不在、EdgeOne 不在。** 也就是说任何"大陆节点"路线都必须**额外持有一台（或一份）上述资源**：

- 最便宜的合规资源：**Lighthouse ¥35/月**（入门型 2核2G / 40GB / 2Mbps / 100GB 月流量），要求**包年包月 ≥3 个月**，备案期间剩余有效期 ≥1 个月
- ⇒ **全年地板价 ≈ ¥420**（列表价；半年以上有时长折扣，系数未核实）

**这一点很反直觉**：CDN 本身可以很便宜（几元～十几元/月），但**为了拿备案资格而必须买的那台服务器才是真成本**，而且它自己就能直接托管站点 —— 再叠一个 CDN 属于重复付费。

**（3）用个人主体备案给商会网站，是明文红线，不是灰色地带。**
甘肃管局要求个人备案人签署承诺书，原文：

> "本网站是个人网站，**不含有企业、单位等非个人网站的信息**，若在核实中发现网站中含有企业、单位等信息，本人愿接受以虚假信息进行备案，**注销网站，并将主体和域名加入黑名单**的处罚"

腾讯云亦规定个人备案的网站名称「不能涉及到"某公司""某团体"」「必须与**主体性质相符**」。
而本站必然出现商会名称、会员企业名录 → **按定义即为不实申报**。

> ✅ 好消息：**社会团体可以用自己的名义做单位备案**，腾讯云的证件表明确把「社会团体」对应到 **《社会团体法人登记证书》**，**不需要营业执照**。
> ⚠️ 但甘肃管局规则页写「其他单位必须选择**组织机构代码证**」（措辞陈旧）→ 这是最可能被驳回的点，提交前建议打 **0931-8781105**（甘肃省通信管理局）确认。

来源：[备案云资源](https://cloud.tencent.com/document/product/243/18908)、[腾讯云备案所需材料](https://cloud.tencent.cn/document/product/243/18914)、[甘肃管局备案要求](https://cloud.tencent.com/document/product/243/51717)、[Lighthouse 价格总览](https://cloud.tencent.com/document/product/1207/73452)

## 4. 决定采用的方向（将来实施时）

这一节记录已经定下来的选择，**不含施工步骤**。

| 决定 | 内容 |
| --- | --- |
| 域名后缀 | **`.org`**（语义最贴切协会；在工信部批复名单内，不堵住将来备案） |
| 域名注册商 | **国内注册商**（阿里云 / 腾讯云）。理由：域名实名认证在国内做，且**在 Cloudflare 注册的域名不在工信部名单内 → 永远无法备案**，等于自断后路 |
| 域名注册主体 | **兰州市商业发展商会**（社会团体法人）。工信部要求单位备案的域名注册者应为单位或其主要负责人 |
| DNS / NS | **NS 指向 Cloudflare，但记录先保持「灰云」（仅解析不代理）**。这样域名先干净上线；将来想挂 CDN 只需点一下橙云，不必再等 NS 生效 |
| 对外地址形态 | **自定义域名的根路径**（如 `https://xxx.org/`），`/syfzsh/` 退役 |
| HTTPS | 用 **GitHub Pages 自带的 Let's Encrypt**（免备案、免费、自动）。不要动 Cloudflare 的 `Always Use HTTPS` + HSTS，直到死循环风险弄清楚 |
| 托管 | **继续 GitHub Pages**（仓库、Actions、Decap CMS 全部不动） |

### 4.1 两个必须记住的技术事实

**（1）Cloudflare 免费版挂不上 `/syfzsh/` 子路径。**
Cloudflare 官方可用性表：Origin Rules 的 **Host 头覆盖**与 **DNS 记录覆盖**都是 **Enterprise 专属**（Free/Pro/Business 一律 No）；Snippets 是 Pro 起；请求头改写规则**不允许改 `Host`**（禁用头名）。
→ 所以**唯一可行**的做法是：在 GitHub Pages 设置里填自定义域名。代价是站点搬到**域名根路径**，`/syfzsh/` 永久退役。

> ✅ 这反而正中目标：URL 更干净，而且 `baseURL` 从 `/syfzsh/` 改成 `/` 之后，**上一轮发现的「子路径陷阱」与「离线构建 `build:local` 全站路径失效」两个 bug 一并自愈**。

**（2）顺序反了会死循环。**
正确顺序：**① GitHub Pages 填自定义域名 → ② DNS 保持灰云 → ③ 等 GitHub 的证书签下来（约 1 小时）→ ④ 再开橙云并把 SSL 模式设为 `Full (strict)`**。

- Cloudflare 的 **`Flexible` 模式 + GitHub 强制 HTTPS = 必然无限重定向**（官方文档：Flexible 下 CF 用 HTTP 回源，而源站把所有 HTTP 重定向到 HTTPS → 重定向循环）
- 证书顺序不对会得到 **526**
- Host 头对不上会得到 **404**（不是 5xx —— 因为 GitHub 按 Host 路由）

**（3）`优选IP`（自选 IP）不要用。**
Cloudflare 在 **2024-12-03** 更新 ToS，§2.2.1(b) 明确禁止「让被 Cloudflare 代理的域名的流量被送到**不是 Cloudflare 为该域名分配**的 IP」。**这是明文违规，不是灰色地带**，而且效果本质上不稳定（你钉住的 anycast IP 随时可能被改路由）。

### 4.2 对效果的**预期管理**（很重要）

| 指标 | 预期 |
| --- | --- |
| **速度** | **没有提升。** Cloudflare 免费版无任何大陆节点（China Network 是 Enterprise 专属 + 每个顶级域名要求 ICP）。实测 TTFB 约 **100–200 ms**；社区直接把 Cloudflare 免费版叫「减速器」 |
| **可达性** | **有真实提升。** 访客浏览器不再接触 `github.io` 这个域名，运营商对 `github.io` 的封锁与 DNS 污染被绕开 |
| 品牌 / URL | 有真实提升（去掉 `github.io/syfzsh/`） |
| TLS | 有提升（自有域名 + 自动证书） |
| 成本 | 仅域名费（`.org` 约 ¥60–100/年），零月费 |

> ⚠️ 写清楚这一点，是为了**避免以后失望**：挂 Cloudflare **不是**为了变快，是为了「能打开」和「地址好看」。
>
> **最便宜的真方案是不存在的** —— 没有备案就没有大陆节点，这不是服务商选择问题，是监管前置条件。

## 5. 可达性触发条件（现在就定下来，定期检查）

这是本记录**唯一需要长期执行**的动作，而且不需要花钱。

**测什么**（三网 × 多省）：

```text
目标：
  1) 自有域名首页（如 https://xxx.org/）
  2) 一张原图      /uploads/news/<原图>.jpg
  3) 一张衍生图    /uploads/news/<名字>_hu_<hash>.webp
对照组：https://chihayam.github.io/syfzsh/  （旧地址，用于确认封锁是否只针对 github.io）

记录字段：各省 × 电信/联通/移动 的
  成功率、首字节 TTFB、总耗时、DNS 解析耗时、是否有连接重置

工具：17ce（https://www.17ce.com/）、boce（https://www.boce.com/）、ITDOG（https://www.itdog.cn/）
频率：上线后每周一次，稳定后每半年一次
```

**触发规则（if → then）**：

| 条件 | 动作 |
| --- | --- |
| 自有域名**成功率 < 90%**，或多省首页 TTFB 中位数 **> 3 s** | 启动**备案评估**（此时已无免费手段可用，见 §3） |
| 自有域名可达、**旧 `github.io` 地址不可达** | 正常 —— 说明自定义域名已生效并绕开了封锁。**什么都不做** |
| 自有域名**与**旧地址都不可达 | 说明不是 `github.io` 被封，而是域名/CDN 本身有问题 → 先查 DNS 与 Cloudflare 配置，不要急着备案 |
| 收到 GitHub 关于 Pages 用途的通知 | 启动**整站迁移评估**（政策驱动，与可达性无关） |
| 商会明确要求「会员在全国各地都必须能快速打开」 | 启动**备案评估** —— 这是唯一真解（§3.3） |

## 6. 独立于托管的合规事项（与搁置无关，建议照做）

这一条**不因为「不备案」而消失**：《互联网新闻信息服务管理规定》的适用对象**不以是否备案为界**，只要向公众提供信息服务就受约束。

| 事项 | 说明 |
| --- | --- |
| **「新闻中心」建议改名** | 该规定**第五条**：提供互联网新闻信息服务须取得许可，而该服务**包含"转载服务"** —— 即**转载也要许可**。**第二十二条**：未经许可可罚 **1–3 万元** |
| **建议停止转载微信公众号内容** | **第十五条**：转载只能转**国家规定范围内稿源单位**发布的信息，并须注明来源、原作者、原标题。国家网信办 **1459 家**稿源名单（2025-08 版）之外的号，转载即越界 |
| 建议改名为 | 「行业动态 / 会务公告 / 协会资讯」等，并避免使用「新闻 / 记者 / 报道 / 独家」等词 |
| 判断依据 | 商会自己的**会务通知、活动报道、会员动态、行业调研**一般不属于第二条定义的「社会公共事务报道、评论」→ 通常不需要许可。风险集中在**栏目名**与**转载**这两点 |
| 另一条边界 | 目前免费发通知与名录 = **非经营性**，备案即可。但**一旦会员名录变成收费推广 / 广告 / 付费排名**，就越过非经营性边界，需要办 ICP 许可证（未取得而经营：罚 10 万–100 万 + 责令关闭） |

来源：[《互联网新闻信息服务管理规定》](https://www.gov.cn/zhengce/2017-05/02/content_5728949.htm)、[《互联网信息服务管理办法》](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=3480)
